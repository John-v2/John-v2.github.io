# John-v2.github.io

Space-themed developer portfolio for John Esin-Kenneth, hosted on GitHub Pages.

Live: https://john-v2.github.io

## Files
- `index.html` — home: hero, about me, skills, contact
- `projects.html` — projects page
- `style.css` — shared styles
- `main.js` — nebula, starfield + scroll animations
- `projects.js` — project hover detail boxes (content lives in the `<template>` blocks in projects.html)
